# Product

<!-- uizze:product-schema 1 -->

## Platform

web

## Users

Дизайнеры, разработчики и прототипировщики, которым нужно из текстового описания быстро получить рабочий HTML/CSS/JS — без дизайн-инструмента и без ручной вёрстки. Вторичная аудитория: self-hosted-пользователи и разработчики, разворачивающие продукт у себя (docker compose, mock-режим без API-ключа).

## Product Purpose

Purl превращает текстовый промпт в полную самодостаточную HTML-страницу: генерация стримится в браузер через SSE и рендерится в sandboxed iframe; результат дорабатывается в чате итерациями. Работа автосохраняется, каждый проект хранит историю версий. Успех — пользователь за секунды получает страницу, которую можно скачать, скопировать и уточнить в диалоге.

## Positioning

Self-hostable открытый аналог Vercel v0 / Lovable: полный цикл «промпт → страница → итерация» в одной коробке, с mock-режимом, работающим без внешних API-ключей. Сосед не может честно скопировать: открытый код, docker compose одной командой, отсутствие зависимости от платного провайдера.

## Operating Context

Одностраничное приложение без роутера: два состояния — Landing (заголовок, hero-инпут с ротацией примеров в плейсхолдере) и Workspace (канва предпросмотра + правая панель чата/кода). Анонимная сессия в localStorage, проекты и версии в SQLite. Двуязычный интерфейс (ru/en). Генерация: анализ → дизайн → код, стрим по SSE. Сгенерированный код выполняется в песочнице (`sandbox="allow-scripts"` без `allow-same-origin`).

## Capabilities and Constraints

- Генерация по промпту (тема/стиль фиксированы: dark/minimal).
- Итерации в чате поверх текущего кода.
- Автосохранение проектов, история версий.
- Mock-режим без LLM_API_KEY. Лимиты: 2000 символов промпта, rate-limit анонимных запросов.
- Песочница iframe: никакого allow-same-origin; генерируемый код не касается хоста.
- Тёмная тема — единственная (dark-first, `class="dark"` на html).
- Технологии: React 19, Vite, Tailwind v3, zustand; бэкенд FastAPI + SQLite. Тесты: vitest, playwright e2e.

## Brand Commitments

- Название «Purl», двуязычность интерфейса (ru/en) через i18n-словари.
- Open-source, MIT, самохостинг.
- Пользователь (владелец проекта) дал полную свободу на визуальную идентичность, включая логотип; имя и функциональность сохраняются.
- Зафиксированное пользователем направление интерфейса: «инструмент мастера», тёмная комната (darkroom) — мир, выбранный 17 авг 2026.

## Evidence on Hand

Реальный контент: i18n-словари ru.ts/en.ts. Бэкенд сидирует 8 шаблонов, но фронтенд их не рендерит. Демо-данных, отзывов, кейсов, цен нет — не выдумывать. Логотип purl-mark.svg существует, подлежит редизайну в рамках нового мира.

## Product Principles

1. Человек пришёл работать: интерфейс — сцена для генерации и итераций, не витрина.
2. Результат (предпросмотр) — единственная светлая поверхность; всё остальное — рабочая темнота.
3. Энергия не враг доверия: характер допустим, если не мешает задаче, состоянию и знакомым аффордансам.
4. Не ломать поведение: SSE, чат, автосейв, версии, i18n и e2e-флоу остаются рабочими.
5. Каждая деталь принадлежит миру: никаких чужих эстетик (индиго-дашборд, стекло, градиенты) в оболочке.

## Accessibility & Inclusion

WCAG 2.2 AA для текста (≥4.5:1), focus-visible на всех интерактивных элементах, поддержка клавиатуры, prefers-reduced-motion. Двуязычность для ru/en аудитории.
